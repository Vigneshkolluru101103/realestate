# ZapDocs Broker Frontend

Standalone Frontend application for the **ZapDocs Real Estate Broker Portal**.

## Tech Stack
* **Framework**: React 19 + Vite
* **Routing**: React Router 7
* **State & Auth**: BrokerAuthContext & BrokerStateContext
* **Styling**: Vanilla CSS + Modern Tokens

## Getting Started
1. Copy `.env.example` to `.env` and fill in the required values:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm test
   ```
